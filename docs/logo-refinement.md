# Smooth-star integration

The request changes Orbit's logo silhouette. The smooth monochrome twin stars
now replace the stepped mark in the header, selected Orbit Client artwork, its
home-list row, the production sources and native app icons. Normal vector
antialiasing replaces crispEdges; no blur or logo motion is introduced.

The dealt style is Framed sheet with a tinted L-frame. The approved brand and
focused request explicitly preserve the existing floating header, alpine
landscape, glass dock, system typography, green controls and responsive layout.
The kit copies and license lines remain in the project. The unused CSS kit's
light tokens now match this run's brand system; loading its global styles would
replace the protected launcher, so it remains unlinked. No charts are needed.

The face and signature are the asymmetric smooth twin-star silhouette. Play's
question remains: which Minecraft instance is selected, and can I play it?
Library retains instance choice and management, Discover retains content search,
Friends retains connection and chat, and Settings retains configuration in its
existing overlay. Their implementation is preserved. The default Play module
loads with bootstrap to avoid the observed empty panel during a separate dynamic
module request. Existing grid arithmetic remains in src/css/home.css.

Verify before publishing: scripts/fixtures/launcher-data.mjs contains isolated
test records for Orbit Client, Survival and Create & explore: their game
versions, loaders, 12/0/34 mod counts, 5400/3600/7200 seconds played and the
4096 MiB default-memory setting. None are imported into production state. The
browser-test facade and Sample data notice live in scripts/check-repair.mjs.
Tests assert 3 installed instances, 46 mods, 16200 seconds played and the
established 4.0 GB default display. Production continues using its native API.

Validation uses the existing local-file browser harness without a preview server.
It covers decoded smooth artwork, static logo rendering, ready, confirmed empty,
unavailable, preparing and running presentations; selection, switcher Escape,
retry recovery and repeated requests; reduced motion; desktop, tablet, phone and
native default/minimum sizes. Native game processes and Microsoft sign-in are
not exercised by the mock backend.

The browser reports document.fonts ready, the existing Segoe UI Variable stack
and positive checks for weights 400/500/600/650. Device-local fonts do not appear
as registered FontFace entries here; no bundled or independently acquired font
is claimed. The approved font-redistribution restriction remains in force.

Native packaging was attempted in offline mode and is blocked by the existing
uncached anyhow 1.0.104 dependency. Icon export and frontend checks succeed.
The landscape, large introduction, glass materials and pre-existing decorative
treatments are explicit preservation exceptions to the general sheet rules.
Full-page word contrast outside the tested navigation/account controls is not
certified by this focused logo change.
